## 1. 本阶段修了什么

1. **autotest sandbox 探测（R32 登记新残余）**：`autotest.ts::probeSandboxRuntime()` 原先**裸 import**
   `@deepseek-ai/dsh-sandbox-windows-acl`（该包只在 Harness `app.asar` 内、仓库上下文解析不到）⇒ DSH-as-node 下
   sandbox 段被误跳过。改用 `resolveDshModuleRoot()` 的**绝对路径**候选 + `createRequire`，与 capability/executor 真实加载口径一致。
   plain node 仍正确判环境错误（exit=2）；DSH-as-node 下 sandbox 段真正运行。

   R21 已定因"读不到 ≠ 挡住"）做**显式 `environmentSkips` 单列**——必须命中 ACL 文案白名单，**不计 checksBad、不伪装 pass**，
   verdictLine 追加 `env-skips=`。

   在 DSH-as-node 运行时下 PowerShell carrier 不具代表性（R18/R19 carrier scope）⇒ SKIP+原因；plain node 仍严格 19/19。
4. **delete-capture V3 两用例显式 SKIP**（`tests/delete-capture.ts`）：`whiteout:V3-outside`/`whiteout:V3-inside`
   （PowerShell `Remove-Item`）在 DSH-as-node 下同口径 SKIP+原因；plain node 仍严格 36/36。
