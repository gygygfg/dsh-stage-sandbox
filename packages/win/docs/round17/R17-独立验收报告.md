   `dsh-desktop-host` / `cordis-plugin-loader` 源码核对加载链（只读，不改宿主）。

### 1.1 关键环境事实（本轮 P0 的根因前提，[实测]）

- 宿主进程（Electron `--expose-internals`，DSH desktop host）**环境块 49/50 项里没有 `DSH_HOME`、没有 `DSH_PROFILE`**
