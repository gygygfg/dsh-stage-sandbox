## 4. ⚠ 环境阻塞（必须知道）

| 阻塞 | 现象 | 影响 |
|---|---|---|
| **`.git` 不可提交** | `git_add` 后 `git diff --cached` 恒为 0；一次成功提交随后从 `git log` 消失 | **阶段 2/3 产物只在工作树，未入库**；需宿主 `git add -A && git commit` |
| 就地改已有文件回滚 | 对"检查点已存在的文件"的就地修改会被回滚 | 已用「删+建」与 `edit_file` 绕过（`.t/regen-ts.mjs`） |
| 无 DSH harness | `@deepseek-ai/*` 悬空到不存在的 `/root/deepseek-harness` | 平台在线验证只能在阶段 4 |
| 网络策略 | `download.deepseek.com` 被拦（403）；`nodejs.org` 被拦 | 安装包须宿主下载 |
| docker 门面 | `run_command` 固定导向不存在的 `/run/neoai-docker/docker.sock` | docker 编排须宿主执行 |

## 5. 交接清单

**宿主需执行**（见 `docs/重构-阶段4-实测runbook.md`）：
1. `curl` 下载 `dsh-latest-windows-x64.exe` 到 `.t/r17/win-shared/`;
2. `cd .t/r17/win11 && docker compose up -d`（compose 已生成）；
3. `ebk-wait` 等就绪 → guest 内装 dsh + 解包插件 + 跑 `verify.ps1`；
4. `ebk-env collect` 取回 `.t/r17/artifacts`。

**入库**：宿主 `cd /root/code/dsh-sandbox-windows && git add -A && git commit -m "重构：Cordis 规范 + 全量 TS + 对齐 NeoAI 审批"`。
