## 1. 新增模块（`plugin/`，全 TS、类型干净、无 `@ts-nocheck`）

| 文件 | 对齐对象 | 内容 |
|---|---|---|
| `plugin/policy/engine.ts` | NeoAI `sandbox/review/policy.lua` | 聚合 `DENY > NEEDS_CONFIRMATION > ALLOW`；约束取更严格交集（数值 min、列表交集）；规则抛错/结构非法 ⇒ `DENY`（fail-closed） |
| `plugin/risk.ts` | NeoAI `sandbox/review/risk.lua` | 安全级别 L0–L3 与 `auto/record/review/block`；**硬拒绝不可被确认覆盖**；密钥/包安装不被会话自动审批跳过 |
| `plugin/approval-hub.ts` | NeoAI `sandbox/review/approval_hub.lua` | 五页分流（files/behavior/resource/network/anomaly）；阻塞类 `submit/resolve`（幂等）；观测类 provider |
| `plugin/review-state.ts` | NeoAI `sandbox/review/review.lua` | `review_state`(PENDING/APPROVED/REJECTED/EXPIRED/SUPERSEDED) 与 `apply_state`(NOT_REQUESTED/APPLYING/APPLIED/CONFLICT/…/NEEDS_ROOT) 双状态线；同路径取代链、环路保护、选择性应用保留 remaining |
| `plugin/commands.ts` | NeoAI 命令语义 | `/winstage-review`、`/winstage-apply --force`、`/winstage-discard`；**逻辑=纯函数、装配=接 DSH**；旧 `/winstage approve|reject` 保留为兼容别名 |

### 1.1 一处**如实差异**（已写进 `engine.ts` 模块头）

NeoAI `policy.lua` 用 `setfenv` + `debug.sethook` 给规则加"受限全局 + 指令/墙钟预算"。
**JavaScript 没有等价原语**（`vm` 不在本插件可用面内；闭包无法回收词法可达的全局）。
因此本实现**只保留** try/catch 归一 + 结构校验，并**不声称**具备"规则无法读文件/发网络"的隔离保证 —— 规则作者须为可信代码。这条与本仓"未提供的保证必须点名"的纪律一致。
