## 2. D1 与长路径：边界钉死，但都没修成

### 2.1 D1（`Get-ChildItem -Recurse`）

shim 写者加了 `R13-CALLMISS` 未命中日志后得到的硬读数：

* 整轮 6 MB+ 的 `shim.log` 里只有 **3–6 条 miss**，**失败那一刻没有任何候选 API 记录**；
* `FindFirstFileExW` **一次都没被调用**；`FindFirstFileA/ExA`（纯透传观察钩子）也一次没被调用；
* 同一棵树上 `Get-Acl` 抛 `DirectoryNotFoundException`（存在且是目录，但**安全描述符面**取不到）。

⇒ 失败发生在"枚举完成之后、PS 提供程序继续下降时"的一个**我们没挂钩**的 API。
**下一步最小改动**：把 `GetNamedSecurityInfoW` / `GetFileSecurityW` / `NtQuerySecurityObject` / `GetFileInformationByHandleEx`
也接进 `R13-CALLMISS`，再跑一次 `Get-ChildItem -Recurse`，最后一个 miss 就是答案。
（写者还记了 3 个自伤坑：run 级 trace 探针的 marker 路径拼接错、`stageRoot` 无固定尾分隔符——已在 `shim-修复.md` §1.4 写明。）

### 2.2 长路径

写者已把 `ws_extend_path` 落在 `ws_stage.c` 的三个出口 + `ws_ensure_dirs` 前缀起点（**<244 字符逐字 no-op**，逃生口 `WINSTAGE_NO_EXTENDED_PATHS=1`），
但它**没能构造出合格验收件**（它试的 227/235/278 字符都抛"访问被拒绝"），因此**不声称修好**。

Lead 用独立验收件复跑（`.t\r13\accept/prompt-r13.txt`，D 段）：

⇒ **仍未修成**；阈值表现与 R12 一致（目录约 155 字符量级失败）。下一次要先把"能稳定构造 200/240 字符逻辑路径"的夹具写出来，再谈验收。

## 4. 32 位 i386：静默崩溃 → 可读的显式拒绝

写者在注入前用 `IsWow64Process2`/`IsWow64Process` 判子进程机器，不一致时写一行 `REFUSED` 日志、
返回 `ERROR_NOT_SUPPORTED(50)` 并终止子进程（不再让远程 `LoadLibraryW` 撞 `0xC0000005`）。

Lead 验收（`.t\r13\accept/out`，B 段）：

```
B_wow_exists=True bitness=10.0.26100.7309
B_wow_run THREW ApplicationFailedException: Program 'cmd.exe' failed to run: The request is not supported
```

⇒ **从"静默崩溃/裸拒绝"变成可归因的显式拒绝**（调用方能读到 `not supported`，审计面有 REFUSED 记录）。
**真支持 32 位**仍需 32 位 shim 构建 + WOW64 注入路径，方案与代价见 `docs/archive/round133/shim-修复.md` §4.2（未实施）。

### 5.2 Lead 的裁决与修复

* **裁决 ②：不做**——不允许 `WINSTAGE_SHELL` 去翻 fs 面的 `config.enabled`。它按设计只管**命令面**（shell 提供方在加载期选定）；
  把两张脸混成一个值会制造新的语义漂移。
* **裁决 ①：做**——界面必须把**两张脸分开如实说**，且面板路由不该只回一个 503 码让人什么都看不到。

实现（`dsh-plugin/**`）：

1. `host-plugin.mjs`：新增并导出 `panelStagingFaces()`；**两处 503 响应体都带上** `staging{effective,configValue,source,shellOverride,faces{file,shell,shellForcedByEnv}}`；
   同时**更正 R12 那段错误注释**（它声称 env=1 会让 fs 面也在跑——实测不成立），闸门保持"只看配置值"。
2. `client.js`：`fetchPanelRoute()` 失败时把响应体带回去 → `readReviewViaRoute()`/`readReview()` 传递 `staging` →
   面板轮询把它写进 store → **设置行的 `readStaging()` 接上 `read.staging`**（旧实现只看 `read.snapshot.staging`，这正是"整行空"的直接原因）。
3. 文案：新增 `faceFileOn/faceFileOff/faceShellEnvOn/faceShellEnvOff/faceShellFollow` 五个键，把旧的一句混合文案换成两句分别署名"哪张脸"。
