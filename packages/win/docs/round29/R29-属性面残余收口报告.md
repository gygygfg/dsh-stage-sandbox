## 2. 修复（file-shim）

### A1：ADS 标记（`shim/src/ws_file.c` + `src/workspace.ts`）
- C 侧：`ws_SetFileAttributesW` **先写 marker（值=显式 attrs，含 `0x80` 清除）→ 再 setattrs**；
  - marker 写失败 ⇒ fail-closed `E5`，不写属性；
  - setattrs 失败 ⇒ 删 marker；
  - 写意图打开 staged 时清旧 marker；
  - delete 随文件消失；rename 随对象移动（旧路径无残留）；目录跳过 marker（避免把可用目录 SetAttributes 退化成 fail-closed；目录 ADS 不可靠）。
- TS 侧：host 优先读 marker（**存在即采用，哪怕 0**）；读失败（非 NTFS 等）⇒ `ATTRIB_MARKER_UNAVAILABLE` 如实 warning 且**不回退旧优先级**；
  apply 成功后清 marker，失败保留供重试；**真实盘不落 ADS**。
- 泄漏面：apply 前真实内容/属性/枚举/流不变；apply 后真实文件无额外命名流（gate-runner E 绿，修后需保持）。

### A2：目录树子项属性逐项恢复（`src/workspace.ts`）
- `_snapshotPath` 递归记录每个子项 win32 属性；`_restoreRollbackSnapshot` 逐项恢复；
- 属性恢复失败 ⇒ `ROLLBACK_ATTRIBUTE_FAILED`，整体如实 `partially-applied`（不谎称 rolled-back）。
