## 0. 一句话结论

**WinStage 的"暂存面 + TS 档"在文件写入方向上依然工作得很好（写入完整性、暂存隔离、候选/审批链、包装完整性都过），但"隔离"这条边界的覆盖面远比 R11 认为的窄**：本轮用"宿主侧真实盘/真实注册表读数"这一独立判据，抓出 **5 条真实盘/真实注册表逃逸或篡改**（MSI 经进程外 `msiserver`、COM 快捷方式经未挂钩的 `NtCreateFile`、显式 32 位视图的注册表键创建/删除、敏感文件写意图 open 的明文 copy-up、混合态下文件面直落真实盘），其中 **MSI 那条本轮已用 fail-closed 策略闸门修掉并真机复验**。

**方法论上本轮最大的收获**：`LANE_OK=true`（TS 档）+ 暂存面在工作 + 真实工作区只有种子，**推不出**"隔离成立"。exe 域实测出现过**四条判据 4/4 全绿、同 run 真实盘 +134.9 MB** 的组合。⇒ 已把"隔离必须由**宿主侧**读数单独判、不得由沙箱内读数自证"写成协议判据 5。
