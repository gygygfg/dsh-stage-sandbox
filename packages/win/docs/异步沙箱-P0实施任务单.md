> **进度（2026-11-19）**：A0/A1a、A2/A3/A4/A5、B0（UI 往返 + base/user 层级）、B1（BOM/CRLF）、B2/B3（队列锁 + provider 漂移 E2E）、C1、C2（按 D-6 显式 pending-restart 收口）、C3（静态 + 运行时 UI）、C0、D0（20 探针 + 错误矩阵/性能）、D1、R34-P1（pip + npm E2E）已落地；`verify-e2e.cmd` 已接线。R49 功能 17/17、UI 11/11、D0 7/7、R34 pip 4/4、npm 3/3、pending 4/4。修复记录见 [FIXES-2026-11-19.md](../../../FIXES-2026-11-19.md)。

> **进度（2026-11-22 · R50）**：B2 的两处"猜原因"收口 ——

## 0. P0 完成定义（DoD）

同时满足以下全部条件才算 P0 完成：

1. **AC-01/02/15/16**：`plugin_manager.list_plugins` 不再弹审批；文件暂存闭环；只读零审批；不合作工具不悬挂。
2. **AC-03/04/17**：开关在可写层事务生效；被更高层（home patch/CLI overlay）覆盖时**写前拒绝并定位覆盖层**；失败逐字节回滚；YAML 保真。
3. **AC-05**：ON→OFF 运行面复原；客户端残留探针零命中；文件面无需重启；命令面热切换（D-6）。
4. **AC-06**：20 条固定探针的模型可见字节 diff 通过；AI-01 仅烟测。
5. **无新增模型可见指纹**：错误矩阵（需求规格 §8.4）逐条通过；用户可见设置错误不进模型上下文。
6. **审计可查**：每次暂存/审批/发布/回滚/设置事务有记录；`/winstage status` 能读出模式、待审、健康。
7. **文档同步**：需求规格、README、本任务单的验收口径一致；新增测试登记到 `src/testrunner.ts` / `verify.cmd`（按现有规则）。

## 1. 工作流与依赖

```text
B1 YAML 保真补丁（独立库）──┐
B0 宿主设置事务 API ───────┴──> B2 开关 UI 接线 ──> B3 多宿主锁（P1 可后置）

C0 单一权威开关（去正则读者） ──> C1 客户端复原账本 ──> C3 残留探针
                                      └──> C2 shell 常驻委托/热切换

A0 宿主审批 seam API ──> A1 动作级分级 ──> A2 队列持久化 ──> A3 answerer/防悬挂
                                      └──> A4 来源 adapter ──> A5 审计/状态

D0 20 探针 + 错误矩阵 ──> D1 路径/env/日志收敛 ──> D2 AI-01 烟测
F0 文件暂存/队列闭环（已有实现）──> E0 E2E 编排与 AC 门禁
```

**建议顺序**（在宿主 API 未就绪时）：

1. **B1/C0/C1**：本仓可独立完成，先消除「开关不生效」「关闭残留」两个用户可见问题。
2. **A0/A1**：需要宿主提供审批 seam；同时把 `plugin_manager.list_plugins` 的只读分级打通。
3. **B0/B2**：宿主设置事务；与 B1 联调。
4. **A2/A3/A4/A5**：队列、answerer、来源 adapter。
5. **C2**：shell 委托 provider；这是「关闭即复原」的最后一块。
6. **D0/D1/D2/E0**：门禁与 E2E 收口。

## 4. 风险与阻塞

| 风险 | 影响 | 处置 |
|---|---|---|
| 直接改 `app.asar`/DSH 内置包会被升级覆盖，且可能破坏签名/完整性 | 不可维护 | 用插件 host 的公开 seam；DSH 侧只提上游 patch（如 `plugin_manager` 只读取值分支） |
| `plugin_manager` 无条件 `approveEscalation`（含 list） | 截图里的旧弹窗 | A1a listener 直接 `allowed-once`；或上游把 approve 移到只读分支之后 |
| `approval.request` 是同步 Promise，工具不支持异步 | 隐藏弹窗会让工具悬挂 | 必须 A3 answerer 立即应答；不可只做客户端抑制 |
| 重放任意工具不安全 | A3 可能误执行 | A3 先限制 allowlist（安装/配置类且可校验前置）；其余 A4 |
| YAML 解析器吃掉 `!!js`/锚点 | 开关写入破坏 profile | 复用 configEditor 的 `parseDocument`；B1 只补 CRLF/BOM 与 fixture；失败不写 |
| 单 shell 服务不能热切换 | C2 可能崩宿主 | 常驻委托 provider；先做 ON/OFF 行为对照，再切注册 |
| 测试夹具 junction 循环 | 扫描/探针误报、超时 | E2E 排除 `.t`/测试 store；用临时 `DSH_HOME` |
| 模型可见面与用户可见面混用 | 设置错误/路径泄漏 | B2/D1 做双面审计；错误矩阵逐条断言 |
