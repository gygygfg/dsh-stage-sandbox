### 4.1 环境跳过：Smart App Control 拦截现场探针

本机若启用 **Smart App Control 强制态**
（`HKLM\SYSTEM\CurrentControlSet\Control\CI\Policy\VerifiedAndReputablePolicyState = 1`），
任何**运行时现场编译**的未签名探针 exe 会被 OS 拒绝（`CreateProcessW` → Win32 **4551**，
“An Application Control policy has blocked this file”）。

`tests/_app-control.ts` 会只读探测该注册表值；下列 8 个套件（7 个 verify 内 + 1 个沙箱段）在强制态下**显式输出**
`RESULT: SKIP … reason=smart-app-control-blocks-fresh-probes`（退出码 0），而不是伪造 PASS、
也不是让关口永久变红：

`r19-shim-boundaries`、`r20-file-boundaries`、`r20-managed-carrier`、`r21-file-adversarial`、`r22-file-advex`、`r23-long-path`、`r27-edge-paths`、`registry-unstaged-wow64`（沙箱段）

SAC 关闭/评估态（0/2）或状态读不到时**不跳过**，套件照常完整运行。复跑条件：关闭 SAC，
或对测试产物做受控签名 / 应用控制策略豁免（管理员）。
