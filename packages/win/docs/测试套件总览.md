## 1. 离线确定性套件（30，`verify.cmd`）

见 `src/testrunner.ts:OFFLINE_SUITES`。任一会话可跑（不依赖 Win32 沙箱）。分三块：

- **手册不变量 / 端到端 / 结构布局**：`selftest`、`e2e-flow`、`struct-layout`、`appcontainer-layout`、`resolve-exec`、`executor-stub`、`audit-parse`、`paths-masks`
- **能力与治理**：`registry-guard`、`workspace-regressions`、`meta-runner`、`appcontainer-runtime`、`probe-selfkill-guard`、`netpolicy`、`mitigations`、`limits`、`integration-wiring`、`wfp-layout`、`sandbox-audit`
- **守门（SSOT / 封印 / 装配 / 审批）**：`suite-wiring`、`residual-baseline`、`policy-never-consistency`、`baseline-integrity`、`dsh-patch-guard`、`boundary-degraded-failclosed`、`whiteout-candidate-capture`、`assembly-toggle-selftest`、`session-enclosure-selftest`、`environment-gate`、`plugin-approval-align`

未登记但在册的辅助/一次性脚本见 `tests/suite-wiring.ts` 的 `KNOWN_UNREGISTERED`（每条带理由）。

## 4. 改了代码后的闸门（必做）

1. `tsc --noEmit -p tsconfig.json` → 0 错误；
2. 跑受影响的离线套件（尤其 `suite-wiring` / `baseline-integrity` / `policy-never-consistency`）；
3. **重封源码基线**（改了封印面文件后）：
   `node tools/baseline-sha256.ts --write` → **复核清单 diff** → `--check`；
4. 新增套件要**同时**登记进 `src/testrunner.ts` 与 `verify.cmd`（否则 `suite-wiring` 红）。

## 5. 收录面与封印（整理轮更新）

`tools/baseline-sha256.ts` 的 `INCLUDED_GLOBS` 现为：

```
src/*.ts  tests/*.ts  dsh-plugin/*.ts  plugin/*.ts  dsh-plugin/*.yml  tools/*.ts  e2e/**/*.ts
```

- 前 6 项是历史「深度 1」面；`e2e/**/*.ts` 是本轮新增的**递归**面（收编的探针 + 测试台 lib）。

- **不**入封印：`e2e/guest/*.{ps1,cmd,bat}`、`e2e/domains/**/*.{ps1,py,cjs,md,json}`（载体/归档，保持原语言）——
  这是一条**如实声明的残余**：guest 载体的内容不受逐条哈希封印。
