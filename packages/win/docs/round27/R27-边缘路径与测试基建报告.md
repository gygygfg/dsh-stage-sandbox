## 1. R27-A（file-shim）边缘路径（方案 A）

### >4096 极端路径
- 事实（修前）：`\\?\` 4096/8192/16000/32000 的写/建目录/rename/delete/read/stat 全部 fail-closed，
  真实盘零写；但读/stat 报 `ERR2`、33000 字报 `ERR206` 等，**不可归因**；根因 `winstage_internal.h::WS_PATH_MAX=4096`。
- 决策（Lead 拍板 **A**）：本轮**不**扩大中央常量（664 处栈缓冲、单帧可能 ~640KB，晚期改风险 > 收益；
  NT 上限支持留专项）。改为：
  - `ws_file.c` 动态 edge guard（上限 = `WS_PATH_MAX - (len(stageRoot)+24)`，覆盖 `\fs\/\wo\/_unc\` 映射开销），
    覆盖 create/open/read/stat/delete/rename/mkdir/remove/copy/hardlink/replace/findfirst（W/A）；
  - 超上限统一 `ERROR_ACCESS_DENIED` + 日志 `fail-closed: path >= shim edge limit (R27 edge; …)` ⇒ **可归因、真实盘零写**；
  - >32767 同样 fail-closed（不再直透真实 API 的 ERR206）。
- 支持口径（实测）：stage 根 ~55 字时 ~3912 可暂存、4062 起拒绝；suite stage 根 ~80 字时 **1k/2k/3k/3.8k 支持、
  ~4.06k 起显式 fail-closed**。文档/§13 已写公式与上限。

### rename 跨卷（C: ↔ D:）
- 现状（无需产品改动）：`MoveFileExW(..., MOVEFILE_COPY_ALLOWED=2)` 跨卷注入后 **RENAME ok=1**：
  视图 dst 内容正确、视图 src ENOENT；**真实 C: 源仍在、真实 D: 目标不存在、真实盘零写、无半态**（copy-up+whiteout+新条目）。
- 文档如实声明：这是 **overlay copy-up**（把真实 `EXDEV` 变成暂存内成功），**不是真实移动**；`flags=0` 同形无半态。

### 真实远端 SMB
- 本机只有回环 `\\?\UNC\localhost\C$`（可用但**非远端**），无第二台 SMB 主机/无管理员建共享 ⇒ **环境缺口**；
  测试记录"远端读未暂存失败、远端写仅 overlay 暂存、回环 UNC 明确标注非远端、`net use` 无远端映射"，
  **不写成"真实远端 SMB 已验证"**。

### 读数
- 新套件 `tests/r27-edge-paths.ts`：**15 断言 / 0 失败**（私有 out）；R26 canonical 红 **15/6**
  （stat=ERR2、32000 rename 截断伪成功、无 R27 edge 日志、33000 字 ERR206）。
- 回归（私有，隔离 stage 根）：`r23-long-path` 13/0、`r21-file` 24/0、`r20-file` 22/0、`r19-file` 17/0、
  `r22-file-advex` 12/0、hello64 `HELLO-MANAGED`、批量枚举 node/cmd/PS 130/130；0 warnings。
- 最终 canonical（Lead 复跑）：`r27-edge-paths` 15/0、`r23-long-path` 13/0、`r21-file` 24/0。
- 环境事实（写 findings）：本 harness 下**子探针不能直接写 `%TEMP%`/`D:`**（node 可写）⇒ 独立探针夹具放可写 workspace，
  否则会把环境限制误判为产品失败。

## 5. 残余（R27）

1. **>4095 路径不支持**（内部 `WS_PATH_MAX=4096`；>4095 显式 fail-closed + 归因）；NT 上限（≤32767）支持留专项。
2. **跨卷 rename 是 overlay copy-up**（暂存内成功、真实盘零写），不是真实移动/EXDEV 语义。
3. **真实远端 SMB 未验证**（环境缺口）；本机回环 UNC 已覆盖。
4. **CodeIntegrity 策略环境**：机器策略会拦截新构建的未签名探针（非产品）；CI 需签名/排除。
5. 继承 R20–R26 其余残余（读取面 R1、raw syscall、未 hook 面、默认 T1/T0 无 WAL、宿主 CLI R21-LC-05 等）。
