## 1. R24-A（fs-policy）生产接线

### A1 `readPolicy` 生产通道（关闭 R21-FS-R1）
- `dsh-plugin/fs-entry.ts:48-65`：读 `WINSTAGE_READ_POLICY`，非空字符串原样透传（entry 不归一，防两套口径漂移）。
- `dsh-plugin/staging-fs.ts:565`：唯一归一入口 `normalizeReadPolicy()` —— 未设/`null`/空/纯空白 ⇒ `record`
  （**默认不变**）；`record`/`block` ⇒ explicit；**其它非空 ⇒ fail-safe `block` + `source:'invalid-fail-safe'`

### A2 自定义 mask 生产来源（关闭 R21-SENS-R1）

  + interface + `FIELD_NAMES` + `stringArrayOf()` 归一（不逐元素静默丢弃）；`dsh-plugin/schema.ts` 手写 schema 同步
  `masks` 字段，并修 **R24-A3（P3）**：schemastery 数组字段文档应为 `inner`（旧写 `list` 会让设置页水合报错）。

  （`{id,pattern,reason,hard:false}` —— 自定义规则走**值级掩码**，不被抬成 danger 整份省略）；**非法正则/空串/非字符串 ⇒
  全有或全无 fail-closed**（先 logError 再抛 `WINSTAGE_CONFIG_MASKS_INVALID`，逐条点名 index）。

## 2. R24-B（file-shim）R14 收窄：批量 apply 原子性

- **实现**（`src/workspace.ts`）：`applyCandidate` 应用前为**本批所有将写路径**建内存回滚快照（原 bytes/mode/
  不存在标记 + 新建祖先；目录树递归 + 树哈希）；`maxSnapshotBytes` 默认 **64 MiB**，超限/不可读/符号链接 ⇒
  **应用前 fail-closed**（`ROLLBACK_SNAPSHOT_TOO_LARGE/UNAVAILABLE`，零写）。
- 中途失败 ⇒ 停止后续写、**逆序回滚**（恢复 bytes+mode、删除本批新建文件/目录、清空新建祖先）⇒
  `status='rolled-back'`、`rolledBack=true`、`rollback[]` 明细、`applied=[]`、候选回 pending 可重试；全成功 ⇒ 快照丢弃。
- 回滚失败 ⇒ 如实 `partially-applied` + `rolledBack:false` + 逐条 rollback 结果（未恢复条目按仍 applied 更新 manifest/queue）。
- 并发守卫：`_rollbackGuard()`（当前==快照 ⇒ noop；==本批 after hash ⇒ 恢复；否则 `ROLLBACK_CONCURRENT_MODIFICATION`
  拒绝覆盖）+ 回滚前重读候选（另一进程已 applied ⇒ `ALREADY_APPLIED` 跳过）。
- **红→绿**：新套件 `tests/r24-atomic-apply.ts`（**13 断言**）修前 **FAIL 13/11**（真实盘停在混合态、无 rolled-back/
  回滚明细）→ 修后 **13/0/0**；覆盖修改/删除/新建/建目录回滚、只读 mode、幂等重试、回滚失败诚实、快照上限 fail-closed、
  stale 预检。`r21-file-adversarial` B2 断言更新为 rolled-back（仍 24/0）；`r19-file` A3.3 经授权更新为
  "junction 逃逸条失败 ⇒ 整批回滚"（17/0）。
- 回归（隔离 stage 根）：r20-file 22/0、r22-file-advex 12/0、r23-long-path 13/0、selftest、e2e-flow、
  workspace-regressions 全绿。
- **残余**：极端"另一进程已写但未 save"窗口（无跨进程锁）、64 MiB 快照上限、mtime 不还原（内容/mode 语义）。
